# 431132 时序相位边界标注规范（P0）

> **版本：** v1.0  
> **适用范围：** `limx_box_transport / 431132` 全量 780 ep  
> **层级：** L2 时序相位（8 类）  
> **配套：** [`431132-commercial-annotation-plan.md`](./431132-commercial-annotation-plan.md) · [`431132-annotation-sop-training.md`](./431132-annotation-sop-training.md)

本规范用于 **统一所有标注员判据**，解决 reach / pre_grasp 等模糊边界。标签 ID **不修改**，仅明确起止帧语义。

---

## 1. 总则

1. **时间轴分段不重叠**；同类连续动作合并为一段。  
2. **以视觉可观测为准**：头摄 320×240，看不清时保守标 `idle` 或 `notes` 说明。  
3. **一箱一周期**：标准顺序为 `reach → pre_grasp → contact → lift → transport → place → release`；箱间用 `idle` 分隔。  
4. **不编造画面外动作**：视频从半路开始/结束，只标可见部分。  
5. **原子技能（L1）由本规范推导**：P1 的 3 段技能边界见 §8。

---

## 2. 八类相位定义与边界

### 2.1 `idle` — 空闲

| 项 | 判据 |
|----|------|
| **进入** | 无明确搬箱目标动作；等待下一箱；任务开始/结束站立 |
| **退出** | 机身或手臂开始朝**某一目标箱**移动 |
| **典型** | 两箱之间站立；episode 开头未动手；全部搬完后的等待 |
| **易错** | 不要将缓慢行走前的「短暂停顿」标成 idle，若已在朝箱移动应标 reach |

### 2.2 `reach` — 接近（机身行走趋近）

| 项 | 判据 |
|----|------|
| **进入** | 机器人朝目标箱**移动**，尚未进入手部预抓姿态 |
| **退出** | 机身基本就位，**手部开始**张开/伸展/对准箱体（见 pre_grasp） |
| **核心语义** | **纯机身行走趋近**；手部无主动预抓动作 |
| **与 pre_grasp 分界** | **reach = 走；pre_grasp = 手**（见 §3） |

**正面示例：**

- 双足走向堆叠箱区，手臂自然下垂或小幅摆动 → `reach`  
- 停在箱前约 0.5m，然后手臂明显伸出对准箱 → reach 在「停步且手未伸出」处结束  

**反面示例：**

- 边走边伸手对准箱 → 从**手开始伸出**那一帧起标 `pre_grasp`，之前为 `reach`  
- 手持箱走向传送带 → 这是 `transport`，不是 reach  

### 2.3 `pre_grasp` — 预抓取

| 项 | 判据 |
|----|------|
| **进入** | 机身已就位（或微调），**手部主动**张开、伸展、旋转对准箱体 |
| **退出** | 手或夹具**首次接触**箱体表面（见 contact） |
| **核心语义** | 对准、张开、预调整；**无箱体接触** |
| **时长** | 可能仅数帧；极短时可合并，但**不得**与 contact 重叠 |

**正面示例：**

- 手臂伸向箱顶，手指张开悬停于箱上方 1–2cm → `pre_grasp`  
- 躯干微调 + 手腕旋转对正箱棱 → `pre_grasp`  

**反面示例：**

- 手指已碰到箱面 → 从接触帧起为 `contact`  
- 还在走路、手未动 → 仍为 `reach`  

### 2.4 `contact` — 接触

| 项 | 判据 |
|----|------|
| **进入** | 手/夹具**首次**碰到箱体 |
| **退出** | 箱子被稳定抬起、**离开支撑面**（见 lift） |
| **核心语义** | 接触到抓稳、箱仍贴台面/地面 |
| **重抓** | 滑脱后再次接触：仍标 `contact`（同一箱周期内）；notes 可写 `REGRASP` |

### 2.5 `lift` — 抬起

| 项 | 判据 |
|----|------|
| **进入** | 箱底**离开**支撑面（地面/台面） |
| **退出** | 箱已离地并开始位移走向传送带（见 transport） |
| **核心语义** | 抬升阶段；箱未贴支撑面 |
| **易错** | 刚离地仍垂直上升 → lift；已明显平移走向流水线 → transport |

### 2.6 `transport` — 搬运

| 项 | 判据 |
|----|------|
| **进入** | 持箱**走向**传送带（含转身、绕行） |
| **退出** | 到达传送带旁，开始**下降/对位**（见 place） |
| **核心语义** | 箱在空中或手中，整体位移至放置区 |
| **易错** | 放置区原地小幅调整高度 → 仍可为 transport，直到明确「往下放」动作为 place |

### 2.7 `place` — 放置

| 项 | 判据 |
|----|------|
| **进入** | 在传送带上方/侧面，**下降**箱体并对位 |
| **退出** | **松手前**最后一帧（见 release） |
| **核心语义** | 箱接触传送带或放置面，**尚未松手** |
| **box_cycle** | 仅当最终箱稳定在传送带上且后续有 release，才计 1 箱 |

### 2.8 `release` — 释放

| 项 | 判据 |
|----|------|
| **进入** | 手指/夹具**开始张开**脱离箱体 |
| **退出** | 手与箱**完全分离** |
| **核心语义** | 松手过程 |
| **注意** | release 段数 ≠ box_cycle；只有**传送带上成功放置**的 release 才计入 box_cycle |

## 3. 核心模糊边界：reach vs pre_grasp（必读）

这是 431132 最易不一致的边界。统一规则如下：

```
判据优先级（满足任一即切换）：
  1. 手部开始主动伸向目标箱并对准 → pre_grasp
  2. 仅机身/底座移动，手未做抓握准备 → reach
  3. 手首次碰箱 → contact（pre_grasp 结束）
```

| 观测信号 | 标什么 |
|----------|--------|
| 腿在走，手臂贴身或自然摆 | `reach` |
| 停步或慢移，手臂明显伸出对准箱 | `pre_grasp` |
| 边走边伸手 | 伸手起始帧 → `pre_grasp` |
| 手悬停箱上方未碰到 | `pre_grasp` |
| 手指碰箱 | `contact` |

**培训口诀：** 「走是 reach，手是 pre_grasp，碰到是 contact。」

## 4. 其他常见边界

### 4.1 lift vs transport

| 信号 | 标什么 |
|------|--------|
| 箱刚离地，主要向上 | `lift` |
| 箱已离地且向流水线方向平移 | `transport` |

分界帧：箱子重心开始明显水平移动 toward 传送带。

### 4.2 transport vs place

| 信号 | 标什么 |
|------|--------|
| 持箱行走、尚未在带上方下降 | `transport` |
| 在带上方/侧面下降、对位 | `place` |

### 4.3 place vs release

| 信号 | 标什么 |
|------|--------|
| 箱在带上，手仍扶/夹持 | `place` |
| 手指张开、脱离箱 | `release` |

### 4.4 idle vs reach（箱间）

| 信号 | 标什么 |
|------|--------|
| 放完一箱，站立等待 | `idle` |
| 转向下一箱并开始移动 | `reach` |

## 5. 多箱 episode 切分

1. 每箱标准链：`reach → … → release`。  
2. 两箱之间：`idle`（若仅 1–2 帧转身可并入 reach，但**超过约 0.5s 建议 idle**）。  
3. `box_cycle` = 成功在传送带上完成 `place + release` 的次数。  
4. 失败箱（掉了、未上带）：仍标完整或部分相位；**不计** box_cycle。

---

## 6. 失败与异常（L1.5 结构化枚举 · 终稿）

商用数据 **禁止自由文本备注**；失败信息写入 `skill_cycles[].fail_reason` **英文枚举码**：

| fail_reason 码 | 含义 |
|----------------|------|
| `slip_grasp` | 抓取滑脱 |
| `drop_mid_transport` | 搬运中途掉箱 |
| `place_offset` | 放置偏移 / 未稳定在带上 |
| `incomplete` | 周期相位不完整 |
| `other` | 其他 / 画面问题 |
| `none` | 无失败（成功箱） |

训练与导出使用 **英文枚举码**；界面与保存 JSON **同源显示英文码**（L2 如 `reach`、`pre_grasp`；L1.5 如 `incomplete`、`slip_grasp`）。**界面壳层**（按钮、列表标题、字段名）与 **hint 悬停说明** 可用中文；任务文本、L1 `subgoal`、`outcome` 值保持英文原文。

## 7. 质检抽检规则（组长）

每条试点/抽检 episode 检查：

- [ ] reach / pre_grasp 分界是否符合 §3  
- [ ] 每箱是否有 lift + transport（真搬箱）  
- [ ] release 与 box_cycle 逻辑一致  
- [ ] 无重叠段、无 >10 帧不明空白（除非画面确实 idle）  
- [ ] outcome 与视频直觉一致  

**分歧处理：** 以本规范 §3 为准；争议片段截图存档，批量反馈修订本规范。

## 8. L1 原子技能推导边界（P1 预留）

在 **不改变 L2 标注方式** 的前提下，每箱周期自动映射：

| 原子技能 | 起始 | 结束（含） |
|----------|------|------------|
| `approach_skill` | 该箱周期内首个 `reach` 起始（或前一 `idle` 结束） | `pre_grasp` 起始帧 **前 1 帧** |
| `grasp_skill` | `pre_grasp` 起始 | `lift` 结束 |
| `place_skill` | `transport` 起始 | `release` 结束 |

箱间 `idle` 归属 **上一箱 place_skill 之后、下一箱 approach_skill 之前**，不划入任一技能段。

## 9. 量产强规则锁死判据（终审定稿 · 强制执行）

Tesla/Figure 量产相位为**硬锁规则**，标注员必须按下列像素/运动判据执行，禁止凭感觉模糊划分：

| 相位 | 唯一进入判据 | 唯一退出判据 |
|------|--------------|--------------|
| `reach` | 机体开始移动趋近箱体 | 机体静止或极慢移，且手部**无**张开预动作 |
| `pre_grasp` | 手部开始对位、张开、调整姿态 | 箱体**像素级首次接触**（contact 前 1 帧） |
| `contact` | 手指/夹具首次触碰箱体 | 箱体**稳定离地**前最后一帧 |
| `lift` | 箱体离地且稳定上升 | 进入整机持箱行走（transport） |
| `transport` | 持箱整机行走 | 在传送带上方开始下降对位（place） |
| `place` | 朝向传送带下降对位 | 手部开始松开（release 前） |
| `release` | 手部开始张开脱离 | 手与箱完全分离且箱在带上稳定 |

**reach vs pre_grasp 铁律：** 走是 reach，手是 pre_grasp，碰到是 contact（§3 细则不变）。
