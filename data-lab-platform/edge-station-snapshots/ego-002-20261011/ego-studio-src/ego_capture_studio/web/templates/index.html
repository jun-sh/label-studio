What EgoVerse Captures

Dense annotations and diverse task coverage

The copy below mirrors the public EgoVerse product framing. This deployment implements the capture contract (poses, head, language, task/scene/operator metadata, QC, export) for your own recorders and annotators — it is not affiliated with the EgoVerse consortium.

Ready for Policy Learning

Includes accurate camera poses, 3D head tracking, and dense language annotation.

  • Camera poses — world–camera trajectory as JSONL or SLAM/VIO adapters
  • 3D head tracking — rigid head–camera coupling or external tracker hooks
  • Dense language — timestamped segments in language.json (ASR-ready)

Standardized and Open-Ended Tasks

EgoVerse contains standardized flagship tasks alongside open-ended scenarios across diverse tasks, scenes, objects, and operators.

  • Flagship vs open-ended — task_tier on manifest.json
  • Scenes & operators — scene_id, operator_id
  • Objects & coverage — object_tags, declared dense channels

Offline replay

  • uv run python scripts/make_replay_fixture.py — synthetic MP4 + poses + language
  • uv run python scripts/replay_episode.py — visualize bundle + captions
  • EgoVerse corpus via official download tools (see README)

Live USB capture

  • uv run python scripts/probe_cameras.py — map /dev/video* nodes
  • uv run python scripts/record_usb.py — record video.mp4 into an episode folder
  • Dual streams: video_left.mp4 / video_right.mp4 supported in export

QC & export

  • Gates for required poses/language, pose gaps, overlapping transcripts
  • export/policy_ready_bundle.json for training stacks
  • REST: /api/health, /api/stats
