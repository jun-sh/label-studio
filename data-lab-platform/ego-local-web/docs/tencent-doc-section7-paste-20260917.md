## 7. 视频预览（HTTP，非 UDP）

初版文档中的 **UDP 视频未实现**。设备四路相机通过自研 `preview_server` 提供 **HTTP** 预览（MJPEG / 单帧 JPEG），与网页、App 共用数据端口 **8765**。

### 7.1 端口与职责（热点场景 `192.168.8.1`）


| 端口       | 服务      | 用途                          |
| -------- | ------- | --------------------------- |
| **9100** | TCP 控制桥 | App 启停录制、`change_view`、状态查询 |
| **8080** | 采集网页    | **启停录制**；录制中**单路**主预览       |
| **8081** | 四路预览网页  | **待机**四路 2×2 同屏预览；**无**采集按钮 |
| **8765** | 预览数据面   | 四路 MJPEG/JPEG 实际数据源         |


**说明：**

- **8080 与 9100 并行**，共用同一套采集逻辑，互不影响。
- **8081 仅用于待机检查四路画面**；打开即唤醒低帧率 standby 预览，**不要求四路帧同步**。
- ~~8082 开发页（采集中四按钮切视角）~~ **已废弃**，不再部署。



### 7.2 预览 URL 模板（数据面 `:8765`）

四路 `view_id`：


| view_num | view_id     | 中文  |
| -------- | ----------- | --- |
| 1        | front_left  | 前左  |
| 2        | front_right | 前右  |
| 3        | rear_left   | 后左  |
| 4        | rear_right  | 后右  |



| 格式        | URL                                          |
| --------- | -------------------------------------------- |
| MJPEG 连续流 | `http://{host}:8765/preview/{view_id}/mjpeg` |
| 单帧 JPEG   | `http://{host}:8765/preview/{view_id}/jpg`   |
| 服务状态      | `GET http://{host}:8765/preview/status`      |


`{host}`：手机连热点时为 `192.168.8.1`；实验室有线为 `10.10.10.130`。

**App 约定：** 优先使用 `device_info` / `view_changed` 中的 `preview_mjpeg_url`、`preview_jpg_url`，不要自行拼接错误 IP。

**8081 网页四路**（代理到 8765，与 App 直连 8765 等价）：

- `GET http://192.168.8.1:8081/` — 2×2 四路页面
- `GET http://192.168.8.1:8081/api/preview/cameras` — 四路元数据（`layout: "quad"`）
- `GET http://192.168.8.1:8081/api/preview/{view_id}.jpg` — 单路 JPEG 轮询



### 7.3 待机 vs 采集：几路 preview 是 live？

| 设备状态 | 预览来源 | 四路是否都 live | 典型参数 |
|----------|----------|----------------|----------|
| **idle**（未录制） | `preview_standby` | **是** | ~8fps，边长 ≤640 |
| **warming / recording** | 采集进程旁路 | **否**（仅主预览路） | 主路 ~4fps，边长 384 |

生产环境（ego-001）为 **保证 30fps H.264 写盘**，采集中默认仅开启 **`front_left` 一路**低分辨率 MJPEG 旁路（`OAK_HW_PREVIEW_H264_CAMS=front_left`）。  
因此：

- **待机**：四路 URL 均可用于检查画面（8081 或 App 拉四路）。
- **采集中**：仅**主预览路**（默认前左）保证持续更新；`change_view` 切换到其他 `view_num` **不保证**有 live 画面（可能 503 或停在旧帧）。



### 7.4 `change_view` 语义（修订）

`change_view` 表示 App **切换当前主预览要拉的 HTTP URL**，**不是**设备侧切换相机硬件。

- 待机：四路 URL 均有效，`change_view` 可任意切换。
- 采集中：仅已配置旁路的视角（默认前左）保证 live；**不支持**「录制中四路任意切换均有画面」。



### 7.5 生命周期与冲突

1. OAK 相机与 **8765 端口同一时刻只有一个生产者**（standby 或 采集栈）。
2. 开始录制时会先停止 standby，再启动采集；8081 四路预览可能出现 **1–3 秒**断帧。
3. 预览 HTTP 为**只读**；多客户端（8080 / 8081 / App）同时 GET 不干扰写盘。
4. 采集中若 TCP 断开，**录制在设备侧继续**；重连后根据 `device_info.state` 恢复 UI，**禁止**在 `recording` / `warming` 时重复 `start_recording`。
